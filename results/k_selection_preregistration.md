# 사전 등록 — 요청 개선 시험 (이웃 수 K, 거리 가중), 2026-10-02, 결과 보기 전 작성

## 질문
QC-S의 요청(q 추출)만 바꿔서(재학습 없음), Filtered 대비 recall·diversity 우위를 유지하면서 precision 또는 best-of-N을 올릴 수 있는가?

## 후보 (8개)
- 이웃 수: 전체 모델 기준 K ∈ {8, 16, 32, 64}. 현재 QC-S = K 32, 균등 추출.
- 추출: 균등 / 거리 가중
  - 거리 가중 = 정규화 상태 공간의 거리 d에 대해 가중치 exp(−d² / 2h²). h = 그 상태의 K개 이웃 거리의 중앙값. h = 0이면 균등.
  - usable 이웃만 남긴 뒤 가중치를 다시 정규화한다.
- fallback 규칙은 그대로다(usable 이웃이 없으면 Q 전체에서 균등).

## 선택 (평가 타깃 R 미사용)
- **모델:** 보고 11b의 1/2 규모 모델(Filtered, Quality-Conditioned; 학습 에피소드의 절반으로 학습).
- **검증 상태:** 같은 seed의 학습 에피소드 중 1/2 부분집합에 들어가지 않은 에피소드. held-out 분할과 R은 건드리지 않는다.
  - 그 chunk 중 (상태, chunk) 중복을 제거하고, 전체 학습 풀 τ로 usable인 것에서 최대 1,500개(diversity 256 × 8).
- **이웃 수 대응:** 1/2 모델의 학습 풀은 전체의 절반이다. 그래서 같은 이웃 반경이 되도록 K_val = K_full / 2 ∈ {4, 8, 16, 32}를 쓴다.
- **선택 규칙:** 실행(4코퍼스 × 5 seed = 20)마다 8개 후보를 4지표로 순위 매긴다(recall↑, precision↑, diversity↑, best-of-N↓). 4지표 순위 평균을 20회에 걸쳐 평균하고, 가장 작은 후보 하나를 고른다(전역 선택, 코퍼스별 선택 없음).
  - 동률이면 현재 설정(K 32 균등)에 가까운 쪽을 고른다.

## 확인 (R, 전체 데이터 모델, 한 번만)
- 선택된 후보와 현재 QC-S를 같은 난수 흐름으로 새로 생성한다. Filtered는 보고 09 값을 쓴다.
- **성공 기준 (실행 단위 부호 검정, 20회)**
  1. 선택 − 현재 QC-S: precision 또는 best-of-N 중 하나 이상이 선택 쪽으로 p < 0.05이고, 반대 방향으로 유의한 지표가 4지표 중 없다.
  2. 선택 − Filtered: recall과 diversity가 모두 선택 쪽으로 p < 0.05다.
- 둘 다 만족하면 "개선". 선택이 현재 설정과 같으면 "현재 설정이 검증상 최선".
